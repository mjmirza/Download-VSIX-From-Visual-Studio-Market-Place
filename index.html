VSIX Downloader

Grab any VS Code extension as a VSIX file. Any version, any platform.

Type an app name to search, or paste a marketplace URL or a publisher.extension id such as esbenp.prettier-vscode. Press Enter or click a suggestion to add it. Add as many as you like.

    How it works and is it safe

    What this does

    It asks the official Visual Studio Marketplace gallery service for the version list of the extension you pick, then builds the official Microsoft download link for the VSIX you choose. The file is served straight from Microsoft servers.

    Privacy and safety

    • Runs entirely in your browser. There is no backend, no account, no tracking, and no analytics.
    • It contacts one host only, the Microsoft marketplace gallery. No third party services are involved.
    • Zero dependencies and zero build step. Open the page source and read every line yourself.

    Search by name

    Type a name such as python or docker. A live suggestion list appears. Use the arrow keys and Enter, or click, to add the one you want. Each pick becomes a chip with its own version and platform controls.

    OS specific builds

    Some extensions such as the C and C++ tools ship a separate VSIX per platform. When that happens a platform menu appears so you can choose the right build for Windows, macOS, Linux, or Alpine, on x64 or arm.

    Offline install

    In VS Code open the Extensions view, use the menu in the top corner, choose Install from VSIX, and select the file you downloaded.
